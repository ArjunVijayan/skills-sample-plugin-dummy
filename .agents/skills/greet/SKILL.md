---
name: greeting-skill
description: A skill that allows the agent to greet users in a friendly and personalized manner.
---

When a user initiates a conversation, the agent can use this skill to respond with a warm greeting. The greeting can be customized based on the time of day, the user's name (if known), or other contextual information.

Example usage:
- If the user starts the conversation in the morning, the agent can respond with "Good morning! How can I assist you today?"
- If the user's name is known, the agent can say "Hello [User's Name]! It's great to see you. How can I help you today?"
