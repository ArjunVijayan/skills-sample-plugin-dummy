---
name: repo-intelligence
description: Analyzes the repository to provide insights on code quality, test coverage, and potential areas of improvement and also previous pull request comments. This skill can be used to generate a comprehensive report on the repository's health and provide actionable recommendations for improvement.
---

Generate a comprehensive report on the repository's health, including code quality, test coverage, and potential areas of improvement. The report should also include insights from previous pull request comments to provide a holistic view of the repository's state.

Analyse previous pull request comments to identify recurring issues, common feedback, and areas where the team can improve. Use this information to provide actionable recommendations for enhancing code quality, test coverage, and overall repository health.

Save two md files in the repo root:
1. `repo-health-report.md`: Contains the comprehensive report on the repository's health, including code quality, test coverage, and potential areas of improvement.
2. `pr-comments-analysis.md`: Contains the analysis of previous pull request comments, highlighting recurring issues, common feedback, and actionable recommendations for improvement.
